# Showcase Checklist

## One day before

- [ ] Freeze the exact best checkpoint; do not train it again.
- [ ] Run the complete test suite.
- [ ] Run final evaluation and copy metrics into the report/slides.
- [ ] Test both directions with five saved images.
- [ ] Start the demo once with internet, then test again offline.
- [ ] Save at least six backup before/after screenshots.
- [ ] Copy the repository, checkpoints, results, and slides to a second drive.
- [ ] Confirm Windows will not sleep while plugged in.

## Before entering the room

- [ ] Reboot the laptop.
- [ ] Close games, launchers, Wallpaper Engine, overlays, and extra browser tabs.
- [ ] Connect power.
- [ ] Launch `scripts\launch_demo.ps1`.
- [ ] Load one example in each direction so weights are warm.
- [ ] Open the slide deck and keep backup images one click away.
- [ ] Disable notifications.

## During the demo

- [ ] Use LumiCycle first.
- [ ] State clearly if selecting the external Turbo benchmark.
- [ ] Mention one visible preserved structure.
- [ ] Mention one limitation; do not claim recovered ground truth.
- [ ] If live inference fails, switch immediately to backup screenshots and explain the identical offline pipeline.
